# digital_logic_lab

prerequisites:
- install sphinx-doc

```bash
brew install sphinx-doc
```

create venv:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

- install sphinx-rtd-theme

```bash
pip install sphinx-rtd-theme
```

- install 
  
```bash
pip install myst-parser
```


deactivate venv:
```bash
deactivate
```
